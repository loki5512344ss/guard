| | |
|---|---|

## Цель

Для HTTP-трафика браузер решает PoW быстро и без нагрузки на UI.

## Зачем

PoW у нас работает на уровне TCP-соединения и годится для клиентов с собственным
решателем. Для обычных браузеров нужна страница-интерстишл и быстрый решатель; в
IronShield Rust→WASM заявлен как ~15× быстрее JS (цифра не проверена). Идею берём, код не
копируем (SSPL).

## Scope

- Бенчмарк JS vs WASM на нашей шкале сложности (до реализации).
- Интерстишл для HTTP и выдача pass-токена после решения.

## Non-goals

- Minecraft и другие протоколы без браузера.

## Критерии приёмки

- [ ] Бенчмарк подтверждает выигрыш, иначе задача закрывается как `dropped`.
- [ ] Токен принимается edge; страница работает с Tor/VPN.

## Верификация

Решение на реальных браузерах (Chromium, Firefox).
