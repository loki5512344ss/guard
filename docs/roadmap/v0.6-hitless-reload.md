# v0.6 — Горячая перезагрузка без окна без фильтра

## Цель

Смена XDP-программы и конфигурации без рестарта и без окна, когда трафик не фильтруется.

## Зачем

Сейчас конфиг применяется рестартом (`docs/runbook.md`), а перезагрузка программы через
detach+attach оставляет окно без защиты. Идеи: `BPF_LINK_UPDATE` (ebpfsentinel, идея),
публикация нового конфига только после успешного разбора (XDP-Firewall, MIT), watcher файла
с инкрементальными изменениями (Infrarust, идея).

## Scope

- Замена программы внутри живой ссылки (`BPF_LINK_UPDATE`) с откатом на detach/attach и
  счётчиком откатов в метриках.
- Атомарный reload конфигурации: разобрать → проверить → опубликовать; «время последней
  загрузки» двигается только после успеха, ошибка не оставляет полузагруженное состояние.
- Раздельные домены перезагрузки (лимиты, детектор, списки) со своими блокировками.

## Non-goals

- Миграция состояния conntrack между узлами; изменение ABI карт на лету.

## Критерии приёмки

- [ ] Во время замены программы поток пакетов не пропускает окно без фильтра (тест в netns).
- [ ] Некорректный конфиг при reload не меняет работающее состояние.
- [ ] `SIGHUP`/API reload описан в runbook.

## Верификация

Непрерывный поток hping3 через замену программы: счётчик пропущенных нефильтрованных
пакетов равен нулю.
