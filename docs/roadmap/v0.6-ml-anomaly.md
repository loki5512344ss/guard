# v0.6 — ML anomaly detection

| | |
|---|---|
| Milestone | v0.6 |
| Status | idea |
| Priority | P3 |
| Depends on | собранный датасет атак |

## Цель

Детектор аномалий (Isolation Forest или проще) поверх текущих сигналов EWMA,
репутации и prefix-статистики: ловить медленные, «человеческие» атаки, которые
пороговые правила пропускают.

## Зачем

Пороги легко обходятся медленным ramp-up. Но ML без данных — гадание, поэтому
задача стоит после того, как накопим воспроизводимые датасеты с нагрузочного
стенда.

## Non-goals

- Онлайн-обучение в проде.
- Замена детерминированных порогов: ML — дополнительный сигнал, не единственный.

## Approach

1. Собрать датасеты: нормальная нагрузка + 3–5 типов атак из `deploy/test/stress/`.
2. Офлайн-прототип на Python, метрики precision/recall, сравнение с текущим
   `AttackDetector`.
3. Если выигрыш доказан — перенос в Rust с фиксированной моделью и
   детерминированным инференсом.

## Критерии приёмки

- [ ] Датасет и методология опубликованы в `docs/research/`.
- [ ] Ложноположительные на нормальной нагрузке ≤ текущего детектора.
- [ ] Инференс не добавляет аллокаций в hot path (замер).
