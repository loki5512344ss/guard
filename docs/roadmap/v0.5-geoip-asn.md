## Цель

Фильтрация и репутация по стране/ASN: блокировка нежелательных регионов,
понижение репутации хостинговых ASN, белый список «домашних» сетей.

## Зачем

Feature-флаг `geoip` и `maxminddb` в зависимостях есть, но реализации нет —
«мёртвый код = баг» по правилам проекта. Для VDS-ниши страна/ASN — базовый
фильтр, который конкуренты либо не дают, либо дают только в платной версии.

## Scope

- Загрузка MaxMind MMDB (страна, ASN) при старте; hot-reload файла по SIGHUP или
  таймеру.
- Конфиг: список разрешённых/запрещённых стран и ASN, режим (`drop`/`challenge`).
- Метрики: вердикты по странам/ASN, ошибки чтения базы.
- XDP-путь не трогаем: GeoIP — userspace-фильтр на этапе `Gateway`.

## Non-goals

- Собственная GeoIP-база.
- Блокировка по городу/координатам.

## Approach

1. Абстракция `GeoLookup` (trait) + реализация на `maxminddb`, чтобы тесты не
   требовали бинарной базы.
2. Интеграция в `Gateway::handle_client` после blacklist, до PoW.
3. Fail-fast: `geoip` включён, база не читается → отказ старта с понятной ошибкой.
4. Тесты: фикстура MMDB в `tests/fixtures/` (маленькая, с явной лицензией).

## Критерии приёмки

- [ ] Конфиг валидируется: неизвестная страна/ASN — ошибка, а не тихий пропуск.
- [ ] Нет базы — фича выключена, edge работает.
- [ ] Метрики покрыты тестами; docs/configuration.md обновлён.
- [ ] Лицензия базы и ограничения описаны в документации.
