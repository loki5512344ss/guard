# v0.5 — Аудит XDP-фильтра: ловушки и тесты без root

| | |
|---|---|
| Milestone | v0.5 |
| Status | idea |
| Priority | P1 |
| Depends on | v0.4-xdp-ci-harness |

## Цель

Закрыть класс дефектов, которые другие XDP-фильтры уже ловили в проде, и получить быстрые
тесты парсера без root.

## Зачем

В v0.4 verifier на 5.15 отверг программу из-за мелочи (паддинг структуры). Разбор
XDP-Firewall (MIT) и Minecraft-XDP-eBPF (BSD-3) дал список конкретных ловушек; часть из них
мы, возможно, уже обходим — каждый пункт сначала проверяется по `universal_filter.c`.

## Scope

Проверить и при необходимости исправить (каждый пункт — тест):

- IPv4: `version == 4`, `ihl*4` помещается до `data_end`, underflow `doff`/`ihl`; смысл
  проверки `ihl != 5` на пути без опций.
- IPv6: ICMPv6 — протокол 58 (не 1); любые proto-гейты на v6-пути.
- Порядок: whitelist → blacklist → порт-гейт для не-TCP/UDP (ICMP, GRE): забаненный источник
  не должен проходить «неподдерживаемым» протоколом.
- Маска `/0` и сдвиги в BPF и userspace; префикс > 32 (v4) / > 128 (v6) отвергается.
- Ключи v6: порядок байт и полная 16-байтовая копия — тест загрузчика сверяет байты ключа.
- Карты: размер буферов per-CPU по *possible* CPU, а не online или фиксированному максимуму;
  поведение при заполнении карты throttle/conntrack (fail-closed для непроверенного трафика и
  backoff на вставку, чтобы не сканировать freelist под спинлоком); размеры карт из конфига.
- Раскладка структур C↔Rust: тесты `size_of`/выравнивания для всех общих ключей и значений
  (сейчас `size_of` встречается только в `src/xdp/globals.rs`).
- Сверить с `research/anti-bot.md`: дроп SYN+FIN, SYN+RST, URG, пустых флагов, SYN с payload,
  первого фрагмента с MF — что реально есть в `detect_tcp_bypass`.
- Rootless-тесты: парсерные заголовки `xdp/core/` собираются нативно с ASan/UBSan, прогон на
  собранных буферах (приём XDP-Firewall `tests/packets.c`; альтернатива —
  `BPF_PROG_TEST_RUN` через libbpf-rs), плюс fuzz на тех же байтах.

## Non-goals

- Линейные правила в горячем пути; переписывание XDP на Rust.

## Критерии приёмки

- [ ] Для каждого пункта: «уже корректно» (со ссылкой на код/тест) или исправление с тестом.
- [ ] Нативный ASan/UBSan-прогон парсера в `cargo test` или отдельным CI-шагом.
- [ ] Тесты раскладки структур падают при изменении размера ключа/значения.

## Верификация

`xdp_ci.sh` на KVM-ноде плюс rootless-тесты в обычном CI.
