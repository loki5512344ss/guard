## Цель

Снять накладные расходы userspace-пути по соединению там, где это подтверждено замером.

## Зачем

Infrarust (Minecraft-прокси на Rust) недавно ускорил путь рядом приёмов; применимость к
Rampart неизвестна, поэтому каждый пункт начинается с бенчмарка (`benches/hot_paths.rs`,
criterion). Идеи, код AGPL не копируем.

## Кандидаты (каждый — только после измеримого выигрыша)

- Глобальный аллокатор mimalloc (сейчас системный).
- Кэш status-ответа Minecraft в предкодированном виде (флуд status-ping не доходит до upstream).
- Чтение handshake за один проход; размер pipe для splice; кэш DNS-разрешения upstream.
- Лог в отдельном writer-потоке.

- Single-flight на upstream для status и негативный кэш — в
  [v0.5-minecraft-handshake-hygiene.md](v0.5-minecraft-handshake-hygiene.md).
- Бенчмарк-метод: open-loop нагрузка и стоимость программы — в
  [v0.6-xdp-observability-tools.md](v0.6-xdp-observability-tools.md).

## Non-goals

- Оптимизации без бенчмарка; смена рантайма (см. io_uring).

## Критерии приёмки

- [ ] Для каждого принятого пункта — criterion до/после в `CHANGELOG.md`.
- [ ] Не принятые пункты помечены результатом замера, а не молча брошены.

## Верификация

`cargo bench --all-features` на одном железе до и после; стресс-прогон `xdp_stress.sh`.
